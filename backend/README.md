# Backend

Diretório reservado para os serviços de aplicação do ParkFlow em etapas futuras.

Na Parte 1 não há API, autenticação funcional nem regras executáveis. Python com FastAPI é somente uma opção em avaliação. A arquitetura futura deverá preservar as regras de negócio e os limites definidos na documentação antes que qualquer tecnologia seja confirmada.

Consulte [`docs/requisitos/regras-de-negocio.md`](../docs/requisitos/regras-de-negocio.md) e [`docs/requisitos/escopo.md`](../docs/requisitos/escopo.md).
