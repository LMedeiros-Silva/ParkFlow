# Backend

Diretório reservado para os serviços de aplicação do ParkFlow em etapas futuras.

Na Parte 1 e no Checkpoint 5 não há API nem autenticação real. As regras de negócio do protótipo executam no navegador, em `frontend/src/domain/`, e a autenticação do Checkpoint 5 é apenas simulada. Python com FastAPI é somente uma opção em avaliação. A arquitetura futura deverá preservar as regras de negócio e os limites definidos na documentação antes que qualquer tecnologia seja confirmada.

Consulte [`docs/requisitos/regras-de-negocio.md`](../docs/requisitos/regras-de-negocio.md) e [`docs/requisitos/escopo.md`](../docs/requisitos/escopo.md).
