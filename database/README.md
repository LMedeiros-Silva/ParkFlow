# Banco de dados

Diretório reservado para modelos persistentes, migrações e recursos de banco de dados em etapas futuras.

Nenhum esquema ou banco funcional faz parte da Parte 1 nem do Checkpoint 5; o protótipo guarda dados de demonstração no `localStorage` do navegador. PostgreSQL é uma opção considerada, não uma decisão imutável. O futuro modelo de dados deverá derivar do domínio e das regras documentadas, sem confundir o diagrama de classes atual com um diagrama entidade-relacionamento.

Consulte [`docs/uml/README.md`](../docs/uml/README.md) e [`docs/requisitos/regras-de-negocio.md`](../docs/requisitos/regras-de-negocio.md).
