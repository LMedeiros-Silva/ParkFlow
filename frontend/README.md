# Frontend

Diretório reservado para a interface web do ParkFlow em etapas futuras.

Na Parte 1 não existe aplicação funcional. React é apenas uma tecnologia considerada e poderá ser substituída após a validação dos requisitos, da arquitetura e das orientações acadêmicas da Parte 2.

Uma futura implementação deverá respeitar os requisitos de responsividade, acessibilidade, desempenho e compatibilidade documentados em [`docs/requisitos/requisitos-nao-funcionais.md`](../docs/requisitos/requisitos-nao-funcionais.md).
